# Ignored Directories

The following directories should be ignored during searches or analysis, as they contain generated code, third-party libraries, or build artifacts:
- `node_modules/**`
- `.venv/**`
- `stedding/**`
- `.cocoindex_code/**`
- `.git/**`
- `dist/**`
- `.turbo/**`
- `**/__pycache__/**`

Do not search or modify files inside these directories.
